# PowerMenu Helper (电源菜单助手)

**减少物理电源按键的负担：从默认系统电源菜单关机、重启，以及一键锁屏。**

Reduce the load on your physical power button: open the default system power
menu (power off / restart) and lock the screen with a single tap — no
long-press on the side key, no root required.

> 本项目为原创实现，灵感来自同类工具类应用。代码、界面与图标均为原创，遵循 MIT 协议开源。

## 功能 Features

| 功能 | 说明 |
|---|---|
| 打开电源菜单 | 通过无障碍服务触发系统电源对话框，从中选择关机 / 重启 / 紧急呼叫 |
| 一键锁屏 | 使用系统全局锁屏操作（Android 9+），无需设备管理员 |
| 快捷设置磁贴 | 下拉通知栏点击「电源菜单」磁贴，任意界面一键呼出 |
| 触感反馈 | 触发操作时轻微振动，确认动作已执行 |

## 系统要求

- Android 8.0（API 26）及以上
- 需要开启无障碍服务（仅用于执行「打开电源菜单 / 锁屏」两个全局操作）
- **Android 13 及以上注意**：通过 APK 文件侧载安装的应用，会被系统的「受限制的设置」
  拦截开启无障碍（开关呈灰色），必须先按下方安装步骤放行一次才能开启。这是按
  **安装方式**判断的系统策略，与 targetSdk 无关，任何侧载应用都一样

## 为什么需要无障碍权限？

「打开系统电源菜单」和「锁屏」是系统级全局操作，Android 仅允许无障碍服务
（或设备管理员等特殊身份）调用。本应用：

- **不读取、不收集、不上传任何屏幕内容**（`canRetrieveWindowContent=false`）
- 不申请网络权限，完全离线运行
- 无广告、无追踪、无任何第三方 SDK

## 构建 Build

```bash
gradle assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

需要 JDK 17 + Android SDK 34 + Gradle 8.7（或直接用 Android Studio 打开本项目）。

## 安装使用

1. 下载 APK 并安装（需允许未知来源安装）
2. 打开应用
3. **（Android 13 及以上必须做一次）允许受限制的设置**：进入本应用的「应用信息」页 →
   点右上角「⋮」→ 点「允许受限制的设置」并完成验证。不做这一步，无障碍开关是灰色的。
   - 小米/MIUI：应用信息页若没有「⋮」菜单，先打开一次本应用、从最近任务中划掉它，
     再长按桌面图标 →「应用信息」，菜单即会出现
4. 开启无障碍服务：点应用内「去开启无障碍服务」，在列表中打开「电源菜单助手服务」
   - 小米/MIUI 路径：设置 → 更多设置 → 无障碍 → 已安装的应用；开启时有带倒计时的
     风险提示，等倒计时结束再确认；若提示有应用遮挡，先把全屏手势临时切回按键导航
   - 小米/MIUI 还建议：为本应用开启「自启动」，并将省电策略设为「无限制」，
     避免服务开启后被系统自动关掉
5. 返回应用，点击按钮即可打开电源菜单或锁屏

> 另一种安装方式：通过会话式安装器安装（如 SAI 分割安装器，或电脑 `adb install`）
> 的应用不受「受限制的设置」拦截，装好后可跳过第 3 步直接开启无障碍。

## 常见问题：提示「受限制的设置」

Android 13（API 33）起，系统会拦截**侧载应用**（通过浏览器/文件管理器等非商店
方式安装的 APK）开启无障碍服务（「受限制的设置」）。该限制按**安装方式**判断，
与 targetSdk 无关，**无法通过降低 targetSdk 绕开**（v1.2.0 及更早版本的说明有误，
v1.3.0 已更正）。解决办法只有一次性的手动放行：应用信息页 → 右上角「⋮」→
「允许受限制的设置」，之后即可正常开启。详细步骤和小米/MIUI 的注意事项见上方
「安装使用」。

> 说明：本应用 targetSdk 保持 31 仅为行为兼容（功能仅依赖 API 26+），与上述限制
> 无关；代价是无法上架 Google Play（其要求更高的 targetSdk），本项目走 GitHub
> 分发，无此约束。

若你仍遇到个别定制 ROM 的额外拦截，可同时使用 v1.1.0 引入的**设备管理员锁屏通道**：
激活设备管理员后，「一键锁屏」不依赖无障碍即可使用。
